# 特約事項ひな形 — 過去分包括・口頭合意の書面化（基準日方式）

作成: 2026-09-07 / 対象文書: 発注書「特約・備考」、個別利用許諾条件書「特記事項（4-3 以降の追加特約）」、
出版等許諾基本契約書「特記事項」

## 1. これは何か

「本日（基準日）付の 1 通で、**過去の取引を全部さかのぼって拾い**、**書面のない口頭合意も全部取り込む**」ための
特約条項セット。発注書・契約書が作られないまま走ってしまった案件を、後から一括で書面化・清算するときに使う。

構成は次の 3 層。**A だけを貼っても成立するが、B（別表）を埋めないと実務上の効き目が弱い。**

| 層 | 内容 | 効き目 |
| --- | --- | --- |
| A. 本文条項（第1条〜第12条） | 遡及適用・口頭合意の取込み・追認・清算・優先順位 | 骨格。どの案件でも共通で使える |
| B. 別表1（口頭等合意一覧） | 主要な口頭合意を 1 行ずつ書き出す | 「言った / 言わない」の予防。ここが本体 |
| C. 別表2（過去取引・対価一覧） | 案件ごとの納品日・対価・既払 / 未払 | 清算条項（第7条）の根拠 |

### 設計方針（なぜこの形か）

- **無限定の「口頭合意は全て有効」だけにしない。** 全部有効かつ内容不明だと、後から一方が
  「そのとき別の約束もあった」と主張でき、清算条項が機能しなくなる。
  → 主要なものは別表1に列挙して確定させ、**未記載分は catch-all（第3条第2項）で救いつつ、
    本特約に反する部分は本特約が優先**という順位を明記する。
- **担当者の権限を先に潰しておく。** 口頭合意の最大の争点は「その担当者に決裁権があったか」。
  第4条で相互に権限を確認しておく。
- **遡及の効力発生時点を明示する。** 権利帰属・利用許諾は「成果物の作成日または最初の利用開始日に遡る」と
  書かないと、過去の利用が無許諾期間として残る（第6条）。

## 2. 本文条項（そのまま貼れる版）

> 甲＝発注者（当社）、乙＝受注者・権利者。基準日は本書面の作成日。
> 発注書に貼る場合は「本特約」を「本発注書の特約事項」と読み替える。

```
第1条（定義・基準日）
  本特約において、次の各号の用語は当該各号の意味を有する。
  (1) 「基準日」とは、本書面の作成日である ◯年◯月◯日をいう。
  (2) 「過去取引」とは、名称・形式の如何を問わず、基準日以前に甲乙間で行われた
      発注、受注、業務の遂行、制作、納品、検収、著作物その他の権利の利用許諾、
      支払その他一切の取引（発注書、契約書その他の書面が作成されていないものを含む。）をいう。
  (3) 「口頭等合意」とは、過去取引に関して甲乙間で成立した合意のうち、書面（記名押印又は
      署名のあるものをいう。）によらないもの、すなわち口頭による合意、電話・打合せ・
      会食その他の場における合意、電子メール、チャットツール（Slack、Chatwork、LINE 等）、
      SNS のメッセージ、議事録、メモ、通話録音その他形式の如何を問わない一切の合意をいう。

第2条（遡及適用・過去分の包括）
  1. 本特約は、基準日より効力を生じ、かつ、過去取引の全部に遡及して適用される。
  2. 個別の発注書、契約書、見積書、請求書その他の書面が作成されていない過去取引についても、
     本特約の各条項が当該過去取引に係る契約条件として適用されるものとする。
  3. 本特約は、基準日以後の甲乙間の取引についても、別途書面により異なる合意をしない限り、
     引き続き適用される。

第3条（口頭等合意の確認・取込み）
  1. 甲及び乙は、基準日現在存在する口頭等合意の全てを本特約に取り込み、これを書面化した
     ものとして取り扱うことに合意する。主要な口頭等合意の内容は別表1のとおりである。
  2. 別表1に記載のない口頭等合意についても、本特約及び別表1の各条項に反しない限り、
     有効に存続し、本特約の一部を構成するものとする。
  3. 口頭等合意の存在又は内容について疑義が生じた場合、甲乙は誠実に協議して解決するものとし、
     別表1に記載のある事項については同表の記載を優先する。

第4条（担当者の権限の確認）
  甲及び乙は、口頭等合意を行った各当事者の役員又は従業員が、当該合意につき所属する当事者を
  代表し又は代理する権限を有していたことを相互に確認し、事後に権限の不存在又は逸脱を理由として
  当該合意の効力を争わないものとする。

第5条（過去の行為の追認）
  1. 甲及び乙は、過去取引に関して既に行われた発注、受注、納品、検収、支払、成果物の利用、
     複製、翻案、公衆送信、出版、二次利用及び第三者への再許諾その他一切の行為について、
     本特約の定めに従って行われたものとして、これを相互に追認し、有効なものとして確認する。
  2. 乙は、前項の行為について、契約の不存在、権限の欠缺、利用範囲の逸脱その他の事由を理由として、
     甲及び甲の取引先（甲から再許諾を受けた者を含む。）に対し、差止め、損害賠償、不当利得返還
     その他一切の請求を行わない。

第6条（権利帰属・利用許諾の遡及効）
  1. 過去取引に係る成果物及びその二次的著作物に関する著作権（著作権法第27条及び第28条の権利を
     含む。）その他一切の知的財産権の帰属又は利用許諾の範囲及び条件は、本特約（別表1を含む。）
     の定めるところによる。
  2. 前項の権利の移転又は利用許諾の効力は、当該成果物の作成日又は甲による最初の利用開始日の
     いずれか早い日に遡って生じるものとする。
  3. 乙は、過去取引に係る成果物について、甲及び甲から権利を承継し又は再許諾を受けた者に対し、
     著作者人格権を行使しない。

第7条（対価・清算）
  1. 過去取引に係る対価は別表2記載のとおりであり、甲は乙に対し、同表記載の未払額
     合計 ◯◯◯,◯◯◯円（消費税込）を、◯年◯月◯日限り、乙の指定する口座に振り込む方法により
     支払う（振込手数料は甲の負担とする。）。
  2. 甲乙は、前項の支払をもって、過去取引に関する甲乙間の債権債務が全て清算されることを
     相互に確認し、本特約に定めるもののほか、名目の如何を問わず、相互に何らの債権債務が
     存在しないことを確認する。
  3. 前項の規定は、いずれかの当事者の詐欺その他の不正行為に起因する請求権については適用しない。

第8条（消費税・適格請求書）
  過去取引に係る対価には消費税及び地方消費税を含むものとし、乙が適格請求書発行事業者である場合、
  乙は過去取引に対応する適格請求書を甲に交付する。乙の登録番号：T◯◯◯◯◯◯◯◯◯◯◯◯

第9条（表明及び保証）
  乙は、甲に対し、過去取引に係る成果物が第三者の権利を侵害していないこと、及び当該成果物に
  第三者の素材、フォント、音源、画像その他の著作物を使用している場合には、本特約に定める
  利用範囲について必要な権利処理を完了していることを表明し、保証する。

第10条（秘密保持の遡及適用）
  本特約及び甲乙間の基本契約に定める秘密保持義務は、甲乙間の取引開始日に遡って適用される。

第11条（優先順位）
  本特約、別表1、別表2及び過去取引に係る個別の書面（発注書、注文請書、見積書等）の間に
  齟齬がある場合は、(1) 別表1に個別に明記された事項、(2) 本特約本文、(3) 別表2、
  (4) 個別の書面の順に優先して適用する。ただし、強行法規に反する部分についてはこの限りでない。

第12条（完全合意）
  本特約及びその別表は、過去取引に関する甲乙間の合意の全部を構成する。ただし、別表1記載の
  口頭等合意及び第3条第2項により存続する口頭等合意は、なお本特約の一部として効力を有する。
```

## 5. 運用上の注意（これは条項ではない）

1. **下請法／フリーランス新法。** 発注時に 3 条書面（取引条件明示）を交付していなかった事実は、
   事後の本特約では治癒しない。遡及書面化は是正としては有効だが、「交付済み」とは扱わないこと。
   今後は発注の都度、発注書を先に出す運用へ切り替える。
2. **支払遅延。** 別表2に長期の未払が並ぶ場合、遅延利息・遅延損害金の要否を検討する。
   第7条第2項の清算条項は、乙が納得して署名していることが前提。
3. **清算条項の射程。** 第7条第2項は広い。乙が個人クリエイターの場合、内容を説明したうえで
   署名をもらうこと（説明なしの一括清算は、優越的地位の濫用や錯誤の主張を招く）。
4. **著作者人格権不行使（第6条第3項）。** 個人の著作者に対しては争いのある条項。
   相手が難色を示す場合は「乙は、甲の通常の利用について正当な理由なく著作者人格権を行使しない」
   に緩める。
5. **署名は必須。** 遡及・追認・清算はいずれも乙の意思表示が要る。発注書の一方的発行では足りない。
   本特約は記名押印（又は電子署名）欄を付した 2 通作成、各 1 通保有とする。
6. **基準日を必ず実日付に置換する。** ◯年◯月◯日のまま出さない。

## 6. アプリでの使い方

`/text-snippets`（定型文言ライブラリ）に、カテゴリ「特約・備考」で以下のタイトルで登録済み
（migration `0154_special_terms_retroactive_snippets.sql`）。

- 過去分包括（遡及適用）
- 口頭合意の取込み
- 担当者の権限確認
- 過去行為の追認
- 権利帰属・利用許諾の遡及効
- 過去分の対価・清算
- 優先順位（口頭合意・書面）
- 完全合意（口頭合意存続型）
- 【一括】過去分包括・口頭合意 特約フルセット

発注書の「特約・備考」欄の 📋 文言集ボタンから開き、必要な条項をコピーして貼り付ける。
別表1・別表2 は本 md からコピーして別紙として添付する。
