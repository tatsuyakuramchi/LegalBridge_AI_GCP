# 特約事項ひな形 — カバーイラスト利用許諾（報酬に許諾料を含む型）

作成: 2026-09-07 / 対象文書: 発注書「特約・備考」、個別利用許諾条件書「特記事項」

## 1. これは何か

**著作権は受注者（乙）に留保したまま、特定の書籍のカバーイラストとしての利用を許諾し、
その対価は発注書の報酬に含めてしまう（別途の許諾料・印税を発生させない）**型の特約。

本リポジトリの用語でいうと「受注者帰属（IP は乙のもの）＋ 利用許諾料は固定報酬に内包」の
ケースで、明細を ROYALTY（利用許諾料）0円にせず、固定報酬側に寄せる運用に対応する。

元の要望文はこの2文：

> 受注者はツクモツムギ拡張ブック オバケツムギのカバーイラストへ本成果物を利用することを許諾する。
> 報酬に利用許諾料が含まれる。

このままでも意思は伝わるが、**実務では次の6点が決まっていないと後で必ず揉める**ため、
下記の推奨版で埋めている。

### 確定した許諾条件（2026-09-07）

| 項目 | 内容 |
| --- | --- |
| 地域 | 全世界 |
| 言語 | 全言語（日本語版のほか、翻訳版・海外版を含む） |
| 期間 | 本件書籍の製造・販売・頒布が継続する間 |
| 態様 | 非独占（他社発行の同種書籍カバーへの利用のみ事前通知・協議） |
| 対価 | 発注書の報酬に利用許諾料を内包。別途の許諾料・印税・二次使用料なし |
| 著作権 | 乙に留保。許諾範囲を超える利用は別途書面 |

| 抜けやすい論点 | 埋めないとどうなるか |
| --- | --- |
| 電子書籍版・重版 | 「紙の初版だけの許諾だった」と主張される |
| 宣伝広告での使用（EC 商品ページ・SNS・店頭 POP） | カバー掲載は OK でも広告利用は別、と言われる |
| トリミング・題号ロゴの重ね | 同一性保持権（著作権法20条）の問題になる |
| 印刷会社・取次・配信事業者への再許諾 | 第三者へ渡す行為が無許諾扱いになる |
| 独占／非独占、地域・言語 | 同じ絵が競合書籍の表紙に使われうる／翻訳版・海外版が範囲外になる |
| 許諾範囲を超えた場合（グッズ展開等） | 「報酬に含む」がどこまで及ぶかで対立 |

## 2. 推奨版（そのまま貼れる）

> 甲＝発注者（当社）、乙＝受注者（イラストレーター等）。

```
【カバーイラストへの利用許諾】
１．乙は甲に対し、本発注書に係る成果物（以下「本成果物」という。）を、甲が発行する
    「ツクモツムギ拡張ブック『オバケツムギ』」（以下「本件書籍」という。）のカバーイラスト
    として利用することを許諾する。
２．前項の許諾には、次の各号の利用を含む。
    (1) 本件書籍の表紙、カバー、帯、扉、奥付その他本件書籍内における複製及び頒布
        （電子書籍版、増刷及び重版を含む。）
    (2) 本件書籍の宣伝、広告及び販売促進のための利用（甲並びに取次、販売店その他の
        流通事業者のウェブサイト、SNS、EC サイトの商品ページ、店頭 POP、チラシ、
        カタログ、展示会、プレスリリース及びメディア提供用画像を含む。）
    (3) 前2号の目的に必要な範囲における、トリミング、拡大縮小、色調補正並びに題号、
        ロゴ、帯文その他の文字要素の重畳その他の改変
    (4) 前3号の目的の範囲において、印刷会社、電子書籍配信事業者、取次、販売店その他の
        第三者に対し、必要な限度で複製及び利用させること（再許諾）
３．本許諾の条件は、地域を全世界、言語を全言語（日本語版のほか、翻訳版及び海外版を
    含む。）、期間を本件書籍の製造、販売及び頒布が継続する間、態様を非独占とする。
    乙は、本成果物を本件書籍以外の用途に利用することができる。ただし、他社が発行する同種書籍の表紙又はカバーへの利用については、
    事前に甲に通知し、甲乙協議のうえ決定する。
４．本成果物の著作権（著作権法第27条及び第28条の権利を含む。）その他一切の知的財産権は
    乙に留保される。本条に定める許諾の範囲を超える利用（本件書籍以外の商品への展開、
    グッズ化、他媒体への転用等）を行う場合は、甲乙別途協議のうえ、別途書面により定める。
５．甲は、本件書籍の適切な箇所にイラストレーターのクレジット（表記名：◯◯◯◯）を表示する。
    表示の位置、体裁及び大きさは甲の判断による。
６．本発注書に定める報酬（金◯◯◯,◯◯◯円（税込））には、本条に定める利用許諾の対価
    （利用許諾料）が含まれるものとし、乙は甲に対し、本条の許諾範囲内の利用について、
    利用許諾料、印税、二次使用料その他名目の如何を問わず、別途の対価を請求しない。
７．乙は甲に対し、本成果物が第三者の権利を侵害していないこと、及び乙が本条の許諾を行う
    正当な権限を有していることを表明し、保証する。
８．乙は、甲及び第2項第4号の再許諾先に対し、本条の許諾範囲内の利用について著作者人格権を
    行使しない。
```

### 遡及させる場合（既に入稿・発売済みのとき）

`docs/special-terms-retroactive.md` の基準日方式と組み合わせて、次の一文を足す。

```
９．本条の許諾は、本成果物の納品日又は本件書籍の入稿日のいずれか早い日に遡って効力を生じ、
    基準日以前に既に行われた本件書籍の制作、印刷、発売及び宣伝広告その他の利用も、
    本条の許諾に基づき行われたものとして取り扱う。
```

## 3. 最小版（要望文をそのまま条項化しただけ）

範囲を絞りたい／相手との関係上あっさり書きたい場合。**上記の6論点は未解決のまま残る。**

```
乙は甲に対し、本発注書に係る成果物を、甲が発行する「ツクモツムギ拡張ブック『オバケツムギ』」の
カバーイラストとして利用すること（電子書籍版、重版及び本件書籍の宣伝広告における利用を含む。）を
許諾する。許諾の範囲は、地域を全世界、言語を全言語（日本語版のほか、翻訳版及び海外版を含む。）、
態様を非独占とする。本発注書に定める報酬には当該利用許諾の対価（利用許諾料）が含まれ、乙は当該許諾の
範囲内の利用について別途の対価を請求しない。本成果物の著作権は乙に留保され、当該範囲を超える
利用は甲乙別途協議のうえ書面により定める。
```

## 4. 埋める前のチェック

1. **態様は非独占で確定済み**（2026-09-07 決定。migration 0156）。乙は他用途に使えるが、
   他社発行の同種書籍のカバーへの利用のみ事前通知・協議とした。独占へ変えるなら第3項の
   「非独占」を「独占」に置換し、報酬の水準が見合うか確認する。
2. **報酬額を実額で入れる。** 「報酬に含む」は、含まれる先の金額が書面上で特定されて初めて機能する。
3. **クレジット表記名を確認する。** ペンネーム表記が本人の希望と違うとトラブルになる。
4. **明細の計算方法。** 利用許諾料を固定報酬に内包する運用なので、明細を ROYALTY（利用許諾料）に
   せず固定額で計上する。ROYALTY 0円で立てると検収書に「利用許諾料に含む」行が出て二重表現になる。
5. **相手が個人の場合、第8項（著作者人格権不行使）に難色を示すことがある。**
   その場合は「正当な理由なく著作者人格権を行使しない」に緩める。
6. 続編・改訂版が出る予定があるなら、第1項の対象を「本件書籍及びその改訂版・増補版」に広げるか、
   都度発注に切り替えるかを先に決める。

## 5. アプリでの使い方

`/text-snippets`（定型文言ライブラリ）に、カテゴリ「特約・備考」で登録済み
（migration `0155_cover_illustration_license_snippets.sql`、許諾条件の確定は
`0156_cover_illustration_license_territory.sql`）。

- カバーイラスト利用許諾（オバケツムギ・最小版）
- カバーイラスト利用許諾（オバケツムギ・範囲明記版）
- 報酬に利用許諾料を含む（別途請求なし）
- 利用許諾の遡及発効（発売済み案件用）
- （汎用）カバーイラスト利用許諾 — 書名差し替え用

発注書の「特約・備考」欄の 📋 文言集ボタンから開いてコピーする。
